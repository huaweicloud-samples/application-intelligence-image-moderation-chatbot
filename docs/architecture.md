# 图像审核聊天机器人架构

## 概述

本项目是一个面向即时通讯平台的图片审核聊天机器人，使用人工智能技术自动检测并删除频道中的不当图片内容。

## 架构图

```
┌─────────────────┐     ┌─────────────┐     ┌─────────────────┐     ┌─────────────┐
│  即时通讯平台    │────▶│    APIG     │────▶│  FunctionGraph  │────▶│  EI 图像审核 │
│  (Slack)        │     │  API 网关   │     │  图片审核函数   │     │  服务        │
└─────────────────┘     └─────────────┘     └─────────────────┘     └─────────────┘
                                                        │
                                                        ▼
                                                ┌─────────────┐
                                                │ 即时通讯平台  │
                                                │  删除图片    │
                                                └─────────────┘
```

## 核心组件

### 1. APIG API 网关

- 接收来自即时通讯平台的事件回调
- 提供公开的 HTTPS 端点
- 与 FunctionGraph 函数集成

### 2. FunctionGraph 函数

- 处理即时通讯平台的事件消息
- 验证消息有效性
- 下载图片内容
- 调用图像审核服务
- 执行删除和通知操作

### 3. EI 图像审核服务

- 基于深度学习的图像内容分析
- 检测色情、暴力、恐怖等不当内容
- 返回置信度评分

## 工作流程

1. 用户在频道中上传图片
2. 即时通讯平台向 APIG 发送事件回调
3. FunctionGraph 函数接收并验证事件
4. 下载图片到内存
5. 调用 EI 图像审核服务检测内容
6. 如果检测到不当内容：
   - 调用 API 删除图片
   - 发送通知消息到原频道

## 安全特性

- 验证令牌校验：确保请求来自合法的即时通讯平台
- OAuth 访问令牌：安全地调用平台 API
- 最小权限原则：函数仅具备必要权限
- 敏感信息管理：凭据通过环境变量安全注入

## 技术栈

- **计算**: FunctionGraph (Python 3.9)
- **API**: APIG
- **AI 服务**: EI 图像审核
- **存储**: OBS (可选，用于图片缓存)
